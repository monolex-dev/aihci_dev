# X 계정

공개 파일은 `accounts/<handle>.json`이다. 글 전문은 없다.

| 파일 | 내용 |
| --- | --- |
| `accounts/karpathy.json` | `@karpathy` 표본. 2026-11-18에 monosurf로 로그아웃 페이지를 읽었다. 화면에 있던 타임라인 글 5개. |
| `private/karpathy.json` | 같은 수집의 글 전문. 깃에서 제외된다. |

수집 명령은 공개 파일의 `collection`에 있다. monosurf 0.5.25, `browse`, 뷰포트 1400x1800, 대기 선택자는 `a[href*='/status/']`.

이 계정은 워치리스트에 들어 있다. 나머지 계정은 아직 수집하지 않았다. 글의 `role`은 모두 `unassigned`다.
